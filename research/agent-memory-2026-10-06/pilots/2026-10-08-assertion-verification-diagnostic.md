# Assertion support without unnecessary narrative rewriting

The opt-in `assertions/v2` verifier attaches support to each proposition rather
than demanding one source class for a whole sentence. A remembered method and
the current body's tool limit can coexist in natural prose. Review records
original memory passages or actual binding fields for each assertion and retains
the sentence's draft label for audit. Rendering changes no narrative words.
Missing citations may be resolved from supplied evidence; external sources are
still forbidden. Source membership, exhaustive assertion coverage, source/binding
typing and final outside semantic assessment remain required.

The reviewer must first identify the proposition supported by the original
source, then compare actor, action, relation, channel/topic, time, uncertainty
and outcome with the candidate. This is fallible model judgment, not a semantic
proof. An unsupported proposition or genuine omission still requires correction
or refusal. Neither draft labels nor a real citation can certify its meaning.

The source adapter also distinguishes a human conversational participant from
an indirect human reporter. It previously gave both channels the same narrator
label. The first bounded diagnostic detects the changed speaker topic but falsely
rejects shared conversational participation; those seven calls and their exact
frozen module remain preserved. The correction changes the decoded narrator
classification, not the original source words. It does not grant physical tools
or participation in unrelated reported events. The changed adapter/procedure
is fingerprinted; historical checkpoints cannot silently acquire new acceptance.

## Actual bounded results

The [evidence archive](receiving-api-evidence/assertion-diagnostics-v1) contains
78 hashed members, all 14 physical receipts, raw requests/responses, source
propositions, outside assessment and frozen implementations. Both batches use
native OpenAI Codex Sol 6.1 low, fresh contexts, no tools or native memory. No
rubric, private conversation or outside source enters a receiver request.

After the source-role correction, both faithful controls are accepted: the
shared conversation through the speaker, and the twenty-sentence project/method
account combining memory with the present binding. Every introduced error is
rejected: changed discussion topic, participant, receipt date, claimed repair,
and current physical capability. Replacing the participant also invalidates the
following anaphoric phrase “after that change”; that additional rejection is
grounded in the altered narrative context.

The raw exact-match helper reports four of seven matches, and remains unchanged
in the archive. It incorrectly expects an empty omission list even for candidates
that replace a known fact with an error, and does not anticipate the anaphoric
dependency. Outside assessment separates those legitimate source-restoration
requests from false rejection of a faithful control. Both truthful controls
have empty omission lists; all five mutations are detected. This diagnostic
does not waive any whole-answer completeness or fidelity requirement.

Actual diagnostic consumption is 14 completed review calls and 169,005 known
tokens, with median call time 51.48 seconds. There are no generation, formation
or embedding calls in this archive. Native subscription billing conversion is
unknown. Counts from the failed first batch are included, not discarded.

Validation: 53 focused narrative/client tests pass, including mixed-source prose,
invented source and binding references, unknown/proof separation, literal source
preservation, replay and changed-contract refusal. Exported member and archive
hashes verify. These changes affect the experimental receiving procedure; the
installed production core and live database do not need replacement for this
delivery. Legacy literal and passage protocols remain available with their
preserved implementations.

The next gate is three previously unused fictional narratives, including an
explicit topic different from its communication medium, an indirect human
encounter with a tested result, and a failed same-being action. Then perform the
single complete closing comparison and outstanding transformation recalls.
No full comparison or stage-two qualification is claimed from these controls.
